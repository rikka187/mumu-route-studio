# MuMu 路线工作台

> 本地网页控制 MuMu 模拟器的虚拟位置：地图规划路线、按时间推进位置、叠加抖动与整体偏移。全程只使用 `MuMuManager.exe`，不依赖 ADB、Python 或模拟定位 APK。**仅修改 GPS 位置，不提供计步/步频数据。**

## 功能特性

- **路线规划**：在地图上连续选点，自动连接成路线；支持拖动调整、右键删除、撤销/重做（`Ctrl+Z` / `Ctrl+Y`）、清空和自动缩放。
- **按时间推进**：按“每一遍时长 + 循环次数”运行，支持两种返程方式：
  - 直线返程：终点沿直线回到起点，返程计入里程与单遍时间；
  - 直接重置：只计去程，两遍之间跳回起点，最后停在终点。
- **轨迹参数**：位置抖动、速度变化、位置更新间隔均可调；设为 0 即为匀速直线。
- **整体位置校准**：按东西/南北偏移（米，±10000）统一平移所有发送坐标，支持 1/5/10/50/100 米步长微调，地图紫色虚线实时预览。
- **单点定位**：选中地图、路线点或搜索结果后，可单独发送一次位置，便于在目标应用中核对。
- **路线管理**：保存/加载/删除路线，JSON 导入导出，编辑草稿自动保存在浏览器；参数与点位一起保存。
- **本地安全**：服务只监听 `127.0.0.1`，POST 请求带本地随机 token，拒绝跨站请求。
- **零运行时依赖**：不需要 `npm install`；Leaflet 已内置，仅地图瓦片与地点搜索需要联网（部分网络环境需要代理）。

## 适用范围与限制

- **仅适用于能在 MuMu 中正常运行的 App**：目标应用必须能在 MuMu 模拟器里正常启动、登录并进入运动页面。带反模拟器检测、加固校验或依赖真实硬件传感器的 App，可能在启动时直接退出，本项目无法绕过。
- **只修改 GPS 位置**：通过 MuMu 的虚拟定位接口更新经纬度，不修改加速度计、陀螺仪、磁场或系统计步传感器数据。
- **不能模拟步数/步频**：如果目标应用通过系统计步传感器或加速度计统计步数、评估步频，本项目无法提供这类数据；MuMu 本身也没有 Step Counter / Step Detector 传感器。
- **不保证应用接收**：位置发送成功只代表 MuMu 接受了命令，目标应用是否接收、记录或判定有效，由应用自身决定。

## 工作原理

位置更新只调用 MuMu 自带的命令行接口：

```text
MuMuManager.exe control -v <实例编号> tool location -lon <经度> -lat <纬度>
```

- 地图与路线文件统一使用 **WGS-84**；可选在连接设置中切换 MuMu 接口坐标系（GCJ-02）。
- 路线由本地 Node 服务执行，网页刷新或关闭都不会中断任务；只有停止服务才会结束。
- 位置按“规划路径进度”计算，抖动不累加里程；显示的已完成里程与计划时间不受抖动影响。
- 发送成功仅表示 MuMu 接受了命令，不代表目标应用已接收或记录。

## 环境要求

- Windows 10 / 11
- Node.js **20+**
- **MuMu 模拟器 12**：从 [MuMu 官网](https://mumu.163.com/) 下载安装，并启动要使用的实例（Android 12 / 15）
- **你自己的 MuMuManager 路径**：首次启动会自动查找常见安装路径；如果没找到，需要在右上角“连接设置”里填写 `MuMuManager.exe` 的完整路径，例如 `D:\MuMuPlayerCN\nx_main\MuMuManager.exe`
- 实例编号是多开器中的 `#` 编号，不是端口
- **能访问地图与搜索服务的网络**：地图瓦片来自 OpenStreetMap / CARTO，地点搜索来自 Photon；国内网络下这些域名可能被墙或很慢，通常需要开启代理（梯子）才能加载地图和搜索

## 快速开始

1. **下载并安装 MuMu 模拟器 12**，启动要使用的实例，确认目标 App 能在 MuMu 里正常打开、登录。
2. 双击 `start.cmd`（或在本目录执行 `npm start`），浏览器会打开 <http://127.0.0.1:8765>。
3. 如果右上角显示“MuMu 未连接”，点击“连接设置”，填写**你自己的** `MuMuManager.exe` 完整路径和实例编号，保存并连接。
4. 右上角显示 `MuMu #0 已连接` 后即可使用。
5. 搜索学校/地址，或直接在地图上点选，依次加入路线。
6. 在“运行设置”中填写单遍时长、循环次数与移动参数。
7. 点击“开始移动”；暂停、继续、停止都在下方控制条。
8. 需要关闭后台服务时双击 `stop.cmd`。

Windows 下也可以使用 PowerShell 直接启动（不打开浏览器）：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1 -NoBrowser
```

## 使用指南

### 规划路线

- 搜索地点后点击结果，再点“加入路线”；也可输入 `纬度,经度` 定位。
- 地图上依次点击添加路线点，拖动圆点调整位置，右键删除。
- “浏览模式”下点击地图只选中位置、不新增路线点。
- 路线参数（单遍时长、循环次数、返程模式）修改后立即反映到里程、配速与总时间。

### 运行设置

| 参数 | 说明 |
| --- | --- |
| 单遍时长 | 每一遍的计划时间，暂停时间不计入 |
| 循环次数 | 1–1000 遍 |
| 到达终点后 | 直线返程，或直接重置到起点 |
| 位置抖动 | 沿路线法向的随机偏移，单位米 |
| 速度变化 | 沿路线方向的速度扰动百分比 |
| 位置更新间隔 | 0.5 / 1 / 2 / 5 秒 |

### 整体位置校准

在左侧“整体位置校准”或右上角“整体偏移”中填写：

- 东西：正数向东、负数向西；
- 南北：正数向北、负数向南；
- 支持方向按钮微调，修改后紫色虚线预览，点击“应用偏移”才会生效；
- 偏移不会立即移动当前位置，只影响之后的路线移动与单点发送；
- 开始/暂停中的任务需要先停止才能修改偏移。

### 保存与导入

- “保存当前路线”保存点位与全部参数，同名覆盖；
- 支持导出/导入 JSON（1 MB 以内，WGS-84）；
- 编辑中的草稿会自动写入当前浏览器的 `localStorage`。

## 坐标系说明

- 地图、路线文件、距离与速度统一按 WGS-84 计算。
- 手动输入支持 WGS-84 或 GCJ-02；GCJ-02 会先转换为 WGS-84。
- MuMu 接口默认发送 WGS-84；若模拟器内地图存在固定偏移，可在“连接设置”切换接口坐标系并人工核对。
- 不要将百度 BD-09 坐标直接当作 WGS-84 使用。

## 数据与隐私

- `data/` 保存本机连接设置、整体偏移与已保存路线，**已加入 `.gitignore`，不会上传到仓库**。
- 服务仅监听 `127.0.0.1`，不对外网开放。
- 在线地图瓦片由 OpenStreetMap / CARTO 提供；地点搜索由 Photon 提供，仅在你主动搜索时发送关键词。
- 建议定期备份 `data/routes.json` 和导出的路线 JSON。

## 常见问题

**端口被占用**：说明服务已在运行，直接打开 <http://127.0.0.1:8765>；或先用 `stop.cmd` 停止。

**找不到 MuMuManager**：在“连接设置”中填写完整路径，例如 `D:\MuMuPlayerCN\nx_main\MuMuManager.exe`。

**目标 App 在 MuMu 里打不开或闪退**：说明该 App 可能检测到模拟器（反模拟器 / 加固 / root 检测），这类 App 无法通过本项目使用；本项目只能操作 GPS 位置，不能绕过应用自身的环境检测。

**步数/步频一直是 0**：本项目只修改 GPS 位置，不提供计步传感器数据；如果目标应用依赖系统计步器，只能换真机或另找传感器方案。

**地图瓦片加载失败 / 地图一片空白**：这是网络问题。地图瓦片来自 OpenStreetMap 与 CARTO，地点搜索来自 Photon，国内网络下这些域名可能被墙或很慢，**需要开启代理（梯子）**，或换一个能访问这些服务的网络。也可以点击地图右上角“图层”在 OSM / CARTO 之间切换重试；地图加载不出来时，经纬度输入、路线规划、保存和运行仍可正常使用。

**点击开始后位置不变**：确认未勾选“仅预览”、MuMu 实例已启动，并且目标应用允许定位。

**实际结束时间与计划有偏差**：命令调用耗时、更新间隔和系统调度都会带来误差，本项目不承诺毫秒级准时。
